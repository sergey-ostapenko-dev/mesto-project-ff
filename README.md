Mesto — интерактивное веб-приложение

Mesto — адаптивное одностраничное веб-приложение для публикации фотографий мест, просмотра контента и взаимодействия с карточками пользователей.

Проект реализует полноценную клиентскую логику: получение и отображение данных через API, создание и удаление карточек, управление профилем, лайки, валидацию пользовательского ввода и интерактивные модальные окна.

О проекте

Mesto представляет собой интерфейс социальной платформы, в котором пользователь может управлять своим профилем и взаимодействовать с коллекцией фотографий.

Основной акцент проекта — на работе с динамическими данными и построении интерактивного интерфейса без перезагрузки страницы.

В приложении реализованы:

получение данных пользователя и карточек с сервера;
редактирование профиля;
изменение аватара;
добавление новых карточек;
удаление собственных карточек;
постановка и снятие лайков;
просмотр изображений в полноэкранном режиме;
клиентская валидация форм;
обработка состояний загрузки и ошибок;
адаптивное отображение интерфейса на различных разрешениях экрана.
Основной функционал
👤 Профиль пользователя

Пользователь может:

просматривать имя и информацию о себе;
редактировать данные профиля;
изменять аватар;
сохранять изменения через API.

Формы открываются в интерактивных модальных окнах, а после успешного запроса интерфейс обновляется без перезагрузки страницы.

🖼 Карточки

Для каждой карточки реализованы:

изображение;
название места;
количество лайков;
возможность поставить лайк;
возможность убрать лайк;
удаление собственной карточки;
открытие изображения в увеличенном виде.

Новые карточки появляются в интерфейсе после успешного ответа сервера.

➕ Добавление карточки

Форма добавления карточки позволяет указать:

название места;
ссылку на изображение.

Перед отправкой выполняется валидация введённых данных.

❤️ Лайки

Лайк работает через API и синхронизируется с сервером.

Интерфейс отображает актуальное количество лайков для каждой карточки.

🗑 Удаление карточек

Удаление доступно для карточек пользователя.

Перед удалением предусмотрено подтверждение действия, что предотвращает случайное удаление контента.

🔍 Просмотр изображения

При нажатии на изображение открывается отдельное модальное окно с увеличенной версией фотографии.

Технические особенности
Работа с API

Приложение взаимодействует с сервером для получения и изменения данных.

Основные операции:

получение информации о текущем пользователе;
получение списка карточек;
обновление профиля;
обновление аватара;
создание карточки;
удаление карточки;
добавление лайка;
удаление лайка.

Асинхронные операции выполняются без перезагрузки страницы, поэтому пользовательский интерфейс остаётся отзывчивым.

Валидация

Для пользовательских форм реализована клиентская валидация.

Проверяются:

обязательность заполнения;
корректность URL;
допустимые значения полей;
состояние кнопки отправки.

Ошибки отображаются непосредственно в интерфейсе формы.

Адаптивность

Интерфейс адаптирован под различные размеры экранов:

мобильные устройства;
планшеты;
ноутбуки;
широкоформатные мониторы.

Для построения адаптивного интерфейса используются CSS Grid и Flexbox.

Модальные окна

В приложении используется единый подход к работе с модальными окнами для:

редактирования профиля;
изменения аватара;
добавления карточки;
подтверждения удаления;
просмотра изображения.

Сборка и запуск
Требования

Для запуска проекта необходим установленный:

Node.js
npm
Установка

Клонировать репозиторий:

git clone https://github.com/sergey-ostapenko-dev/mesto-project-ff.git

Перейти в директорию проекта:

cd mesto-project-ff

Установить зависимости:

npm install
Запуск в режиме разработки
npm run dev

Webpack Dev Server запустит локальный сервер и откроет приложение в браузере.

Production-сборка
npm run build

После выполнения команды Webpack создаёт оптимизированную production-версию приложения.

Деплой

Для публикации проекта на GitHub Pages используется:

npm run deploy

В проекте настроен отдельный deploy-скрипт, который сначала выполняет production-сборку, а затем публикует содержимое dist через gh-pages.
